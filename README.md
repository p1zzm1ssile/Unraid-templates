# Unraid-templates

Unraid Community Applications templates for my apps:

| App | What it does | Source |
|-----|--------------|--------|
| **Dubarr** | Removes audio and subtitle tracks in languages you don't want, without re-encoding | [p1zzm1ssile/Dubarr](https://github.com/p1zzm1ssile/Dubarr) |
| **Evictarr** | Keeps your download clients clean for Sonarr and Radarr | [p1zzm1ssile/Evictarr](https://github.com/p1zzm1ssile/Evictarr) |
| **Setuparr** | Checks your Unraid media setup against the TRaSH guides and fixes what doesn't match | [p1zzm1ssile/Setuparr](https://github.com/p1zzm1ssile/Setuparr) |
| **Duplicatearr** | Finds the same film, episode, poster or extra stored more than once, even as different encodes | [p1zzm1ssile/Duplicatearr](https://github.com/p1zzm1ssile/Duplicatearr) |

This repository only holds the Unraid templates (`templates/`) and the Community Applications profile (`ca_profile.xml`). Each app's code, Docker image and licence live in its own repository.

Please report problems on the app's own GitHub issues page.
